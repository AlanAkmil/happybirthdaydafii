# Dafi Naik Level 🎂

Web ucapan ulang tahun buat Dafi, dibuat pakai Next.js + Tailwind.

## Jalanin lokal
```
npm install
npm run dev
```
Buka http://localhost:3000

## Deploy ke Vercel
1. Push folder ini ke GitHub.
2. Import repo-nya di vercel.com/new.
3. Deploy, gak perlu env variable apapun.

Foto Dafi ada di `public/dafi-photo.jpg` — tinggal ganti file itu kalau mau pakai foto lain, nama filenya harus tetap sama.
